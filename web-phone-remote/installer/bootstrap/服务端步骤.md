# 注册服务部署契约

公开 exe 和仓库里没有 FRP 全局令牌。小白用户不用填写令牌，也不用放置 `bootstrap.url`。安装器写死访问：

`https://103.205.240.23:7443/v1/register`

注册失败时，本机远控仍安装完成，公网中转保持未连通。不要把它说成已经通了。

## 你要在 103.205.240.23 上实施

### 1. frps

- 监听 `0.0.0.0:7000`（或该公网 IP）
- `allowPorts` 只放 TCP `10000-10100`
- 全局令牌只来自环境变量，例如 systemd 的 `Environment=FRP_TOKEN=...`
- 不要把令牌写进 git、安装包或工单附件

### 2. 注册进程（只听本机）

仓库文件：`web-phone-remote/installer/bootstrap/server.mjs`

```bash
export FRP_TOKEN='仅在这台服务器上设置'
export ENROLL_OPEN=1          # 只在发放新电脑时打开
export BIND_HOST=127.0.0.1
export PORT=7100
export FRP_SERVER=103.205.240.23
export FRP_SERVER_PORT=7000
node server.mjs
```

`ENROLL_OPEN=1` 时，新的 32 位十六进制 `deviceId` 会从 10000 起得到一个还没被占用的端口，并写进 `ports.json`。同一 `deviceId` 再来会拿回原端口。`ENROLL_OPEN` 不是 `1` 时，未知设备返回 403，已登记设备仍可取回自己的端口和令牌。101 个端口用完返回 409。

进程不要对公网监听。令牌不会打到它的日志里。

### 3. HTTPS

在同一台机器上把 `7443` 反代到 `127.0.0.1:7100`。证书必须被 Windows 信任，并且包含 IP `103.205.240.23`（SAN）。客户端使用系统信任库校验，失败就放弃公网，不会跳过校验。

反代只转发：

`POST /v1/register`

请求：

```json
{"deviceId":"<32位小写hex>"}
```

成功 `200`：

```json
{
  "serverAddr": "103.205.240.23",
  "serverPort": 7000,
  "remotePort": 10000,
  "token": "<服务器环境变量里的 FRP_TOKEN>"
}
```

`remotePort` 必须落在 10000 到 10100。安装器拒绝这个范围以外的端口，也拒绝空令牌。

令牌会在注册成功后写进那台电脑自己的 `frpc.toml`（权限 600）。这是 frps 全局令牌模式的结果，不是把令牌放进公开发布的 exe。登记窗口请尽量短。若窗口期内有不认识的设备登记，关掉 `ENROLL_OPEN` 并轮换 `FRP_TOKEN`，然后让已知电脑再打开一次安装器取新值。

### 4. 客户端行为（已经写在 exe 里）

- 自动 POST 上面的 HTTPS 地址，用户无输入
- 只接受 HTTPS，拒绝明文和跳到明文
- 成功才写 `frpc.toml` 并注册登录后启动的 `PhoneRemote-Frpc`
- 本地网页端口在本机 8000–8099 里挑一个空闲的，固定映射到分配到的远端端口
- 本地服务只绑 `127.0.0.1`
- 安装日志里的令牌和管理员密码会变成 `[已隐藏]`

## 麦克风

`http://103.205.240.23:远端端口` 是明文 HTTP，浏览器不会在这种页面上打开电脑麦克风。本机 `http://127.0.0.1:端口` 可以。远程开麦要另备一张受信任证书，本安装包没有，也不要让用户忽略证书警告。
